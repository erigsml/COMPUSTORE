# COMPUSTORE Landing Page

Esta es la landing page oficial de COMPUSTORE, una empresa dedicada a la comercialización de partes críticas de impresión y soluciones de software.

## 🚀 Características

- **Diseño Minimalista**: Enfoque limpio y moderno con mucho espacio en blanco
- **Identidad de Marca**: Color primario rojo (#CB1B20) con alto contraste sobre blanco
- **Responsive**: Diseño mobile-first que se adapta a todos los dispositivos
- **Accesible**: Cumple con estándares WCAG de accesibilidad
- **Animaciones Suaves**: Transiciones y efectos hover para mejor UX

## 📦 Tecnologías

- **Next.js 15** - Framework React de última generación
- **TypeScript** - Tipado estático para mayor robustez
- **Tailwind CSS** - Utilidades CSS para diseño rápido
- **Inter Font** - Tipografía moderna y legible

## 🎨 Paleta de Colores

- **Rojo COMPUSTORE**: `#CB1B20` - Color primario de la marca
- **Blanco**: `#FFFFFF` - Color secundario para máximo contraste

## 🏗️ Estructura

- **Hero Section**: Mensaje impactante sobre soluciones directas de fábrica
- **Productos**: Grid 3x2 con 6 productos principales
  - Toners
  - Paper Pick Up Rollers
  - OPC Drums
  - Chips de Impresoras
  - Soluciones de Software
  - Kits de Mantenimiento
- **Aliados Estratégicos**: Fuji Electric y MyQ Solution
- **CTA**: Llamada a la acción para contacto
- **Footer**: Información de contacto y enlaces

## 🚀 Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Compilar para producción
npm run build

# Ejecutar en producción
npm start
```

## 📱 Comandos

- `npm run dev` - Inicia el servidor de desarrollo con Turbopack
- `npm run build` - Crea el build de producción
- `npm start` - Inicia el servidor de producción
- `npm run lint` - Ejecuta el linter de ESLint

## 🎯 Accesibilidad

- Etiquetas ARIA en todos los elementos interactivos
- Contraste de color validado (WCAG AA)
- Navegación por teclado completa
- Semántica HTML5 apropiada
- Textos alternativos en imágenes
